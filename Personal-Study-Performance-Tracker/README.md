# 📈 Personal Study Performance Tracker

A command-line Python application for tracking study sessions and learning progress.

## Features

- Add study sessions
- Display all study sessions
- Search by subject
- Remove study sessions
- Show total study time
- Show best-rated subject
- Show lowest-rated subject

## Technologies

- Python 3
- Lists
- Loops
- Functions
- Conditional statements

## Run

```bash
python main.py
```
