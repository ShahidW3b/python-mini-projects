# 📚 Personal Book Collection Manager

A command-line application written in Python for managing a personal book collection.

## Features

- Add a new book
- Display all books
- Search by title
- Update reading status
- Remove books
- Count total books
- Display finished books

## Technologies

- Python 3
- Dictionaries
- Lists
- Loops
- Functions
- Conditional statements

## Run

```bash
python main.py
