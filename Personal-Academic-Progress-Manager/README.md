# 📚 Personal Academic Progress Manager

A command-line Python application for managing academic subjects, study sessions, test scores, learning progress, and study tasks.

## Features

- Add new subjects
- Display all subjects
- Search for a subject
- Update subject progress
- Remove subjects
- Add study sessions
- Record test scores
- Calculate subject average scores
- Calculate total study time
- Find the subject with the highest average
- Add study tasks
- Mark tasks as completed
- View subject progress

## Technologies

- Python 3
- Dictionaries
- Nested Dictionaries
- Lists
- Loops
- Functions
- Conditional Statements
- Exception Handling

## Run

```bash
python main.py
```
